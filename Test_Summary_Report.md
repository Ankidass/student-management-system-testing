# Student Management System Testing — Summary

## Purpose
Demonstrate a manual testing approach for core student-record management workflows.

## Coverage
- Registration and mandatory field validation
- Duplicate student ID/email checks
- Student list, details, and search
- Update, cancel edit, delete, and cancel delete
- Data persistence after refresh
- Navigation, keyboard usability, and access-control checks where applicable

## Artifacts
- `Student_Management_Test_Cases_and_Bug_Report.xlsx`
- `README.md`

## Reporting Guidelines
The test case sheet contains 25 designed test cases with execution status initialized to `Not Run`. The bug-report sheet contains illustrative scenarios, not confirmed defects. Record actual outcomes only after running the steps against a selected Student Management System application.

## Skills Practiced
Test analysis, test case design, functional testing, negative testing, field validation, data integrity testing, defect documentation, and GitHub repository management.
