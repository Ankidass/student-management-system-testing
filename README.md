# Student Management System — Manual Testing Project

## Project Overview
This project demonstrates a structured manual QA approach for a Student Management System, focusing on student registration, record viewing, searching, updating, deleting, form validation, navigation, and data integrity.

## Objectives
- Design clear positive and negative test cases.
- Cover common student-record workflows and form validations.
- Document test case priorities, preconditions, steps, and expected results.
- Use a consistent defect-report format.
- Organize testing artifacts in GitHub for portfolio review.

## Scope
- Student registration
- Student list and detail view
- Search
- Update and cancel editing
- Delete and cancel deletion
- Form validation and data integrity
- Navigation, usability, and access-control checks where supported

## Project Files
- `Student_Management_Test_Cases_and_Bug_Report.xlsx` — 25 test cases and illustrative defect-report examples.
- `README.md` — project overview and test approach.
- `Test_Summary_Report.md` — coverage and reporting approach.

## Test Design Approach
Test cases include positive and negative scenarios, preconditions, steps, expected results, and priority. The workbook uses `Not Run` as the initial execution status so results can be entered accurately when the selected application is exercised.

## Defect Reporting
The defect rows are illustrative examples of how to document a potential issue. A defect should be reported as confirmed only after the behavior is reproduced and the actual result differs from the expected result.
